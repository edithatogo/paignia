# T21 specification

Qualify Paignia against explicit core and application outcomes. Support
verified adoption where its representations and methods match callers.
Improve model exchange and documentation using the versioned native
contracts and existing public examples.

## Deliverables

- Compare Paignia, Gambit and OpenSpiel and freeze a reproducible comparison
  protocol before making relative accuracy or performance claims.
- Document the existing UOGTO RDF and Paignia JSON interoperability profile.
  Validate and publish the mapping, constraints and supported round trips.
- Evaluate generation of game diagrams in Mermaid from an admitted model.
- Inventory each in-scope consumer's game models and production callers in a
  linked child issue. Replace compatible duplicate generic solver code after
  a pinned, tested migration. Record other dispositions with evidence.
- Publish accessible Astro/Starlight documentation with runnable tutorials
  for the released, supported profiles and scoped application cases.

## Acceptance

Use independently derived outputs or comparator implementations before
retiring each legacy production path. Retain numeric tolerances, source
identity and rollback. Verify model equivalence before benchmarking. Publish
an interchange receipt and document unsupported representations. Validate
the site build, links, accessibility and examples. Keep the review manuscript
and the higher-dimensional Nash research leaf in their existing scopes.
