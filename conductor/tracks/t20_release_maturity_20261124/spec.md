# T20 specification

Qualify a citable release of the bounded static provider using reproducible
artifacts, real consumer receipts and a native main-branch check requirement.
Keep the current minimum compiler, isolated package validation, dependency
policy, CodeQL and Offline AI Security controls. Review native requirements
through the actual repository settings. Record repository health findings against
the source they assess. Use the official OpenSSF Project Security Baseline at a
pinned edition and track evidence at the control level.

Extend the FAIR4RS preflight with executable interoperability and release
evidence. Use the JOSS checklist for paper readiness, Inara for an exact draft,
and CODECHECK for independent execution of a frozen computational package.
Paper acceptance and external submission are distinct from repository and release
acceptance. At the day-zero source audit Paignia shipped Rust libraries, so
rOpenSci `pkgcheck` and pyOpenSci review apply when a maintained wrapper exists.

Retain the scientific limits of the segment enclosure. Track a higher-dimensional
feasibility oracle and comparative benchmarks as an independent research leaf.
Adopt additional solver families only after a concrete use case and oracle.
