# Paignia

Paignia is the Rust library for reusable game representations, strategic algorithms and solver diagnostics in the Kairos ecosystem.

This repository is being initialized from the independent Rust game seed previously incubated in [new-drug-reimbursement-game](https://github.com/edithatogo/new-drug-reimbursement-game). Source transfer, native CI and package/consumer qualification are being prepared in the initial pull request. No package release or general solver qualification is claimed by this bootstrap.

UOGTO retains ontology and semantic profiles. Kairos supplies optional simulation execution. Domain applications retain their particular games, payoffs and empirical assumptions. Static Paignia solving does not require a simulation engine.
