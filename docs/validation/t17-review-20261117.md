## Review findings repaired

- **Compiler compatibility:** the receiving `thiserror 2.0.21` required Rust
  1.77 and broke the declared 1.75 contract before any native tests. PR32 restored
  the exact compatible PR27 manifests/lock with `thiserror 1.0.69` and added a
  Renovate major-version constraint. It merged normally as
  `9100b784081c2d046609baa7a2eab79bd42f8c93` after native/privacy success.
- **CI composition and clean caches:** restored the lost 28-test inspection job
  and fixed duplicate workflow keys introduced by an intervening external
  merge. Later clean hosted runs exposed an uncached target-specific metadata
  dependency. `cargo fetch --locked` now precedes offline boundary inspection;
  the full closure check was preserved, not reduced to the host target.
- **Artifact isolation and extraction:** an ancestor Cargo-cache bind could
  expose provider source after the mask. The mask now follows every bind, and
  an actual compiler negative control proves isolation. Archive path aliases,
  duplicate members and directory entries bypassing the member limit reject.
- **Current Cargo packaging:** stable Cargo tried to generate archive locks
  through an unpublished sibling registry dependency. Its documented
  `--exclude-lockfile` option is used where present; Cargo 1.75 already omits
  library locks. Provider/consumer locks and exact resolved identities remain
  checked. Independent review reproduced the unpublished-sibling case on both
  compilers. Exact archive retention rechecks all hashes before copying any file.
- **Mixed-Nash cancellation:** independent review found that naive accumulation
  erased an exact half-unit profitable deviation under `2^54` cancellation.
  A sum-only repair still lost subtraction and product remainders. Distinguishing
  tests failed before fixes. Expansion sums, checked fused-product remainders
  and explicit unrepresentable-range errors preserve those gains without
  loosening tolerances. The corrected 39-test method and 14 external controls
  pass, and the regression also executes from every solver artifact profile.
- **Evidence admission:** fixed duplicate/aliased application identities,
  unbound profile content, failed/zero-test scientific evidence, missing
  individual feature profiles and malformed-path handling. All 30 controls pass.
  This validates the recorded claims structurally; receiving owners still
  assess their scientific and application adequacy.

No production correction was needed after the final independent result, RK4,
static-conversion, CE or observation reviews. Their documentation preserves
method limits and the differences between source binding, mathematical
admission, native authority and actual application evidence.
